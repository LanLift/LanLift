# LanLift 0.2.0 使用與升級說明

## 本版更新

| 功能 | 行為 |
|---|---|
| **單版本資料保留式升級** | 安裝程式偵測到既有 LanLift 時，會以新版取代舊版，因此電腦上只保留一個 LanLift 程式版本；Windows 使用者資料、接收資料夾偏好與伺服器紀錄不會被移除。 |
| **精簡 Windows Setup** | 僅保留繁體中文與英文 Electron 語言資源，將 Setup 由 0.1.1 的 **91 MB** 縮減為約 **84 MB**。Electron 執行環境仍是安裝包的主要體積來源。 |
| **左側裝置圖像** | 首頁的裝置插圖已移到左側，文字與建立傳輸操作位於右側。窄視窗仍會安全收合版面。 |
| **批量檔案摘要** | 佇列預設只顯示前三個檔案與總數；可按「顯示其餘 N 個檔案」展開完整清單。資料夾仍會自動壓縮為 ZIP。 |
| **連線方式** | 可在「直接連線」與「自訂伺服器」之間切換；不包含共用免費中繼或預設遠端服務。 |
| **伺服器紀錄** | 可新增、編輯、選用及刪除多組伺服器；訊號網址、TURN 位址、使用者名稱與最後使用紀錄會保存。敏感憑證使用 Windows 系統資料保護保存，不會以明文顯示在介面或設定檔。 |

## 安裝與升級

請執行 `LanLift Setup 0.2.0.exe`。若系統中已有 LanLift，安裝程式會提示這是一次更新，並將程式更換為 0.2.0。此流程**不會**建立第二個版本，也不會主動清除以下使用者資料：

- 已選擇的接收資料夾；
- 已儲存的自訂伺服器紀錄；
- 已加密的自訂伺服器憑證。

> 若希望完整移除所有資料，請先在 LanLift 中刪除伺服器紀錄，再透過 Windows「已安裝的應用程式」解除安裝。接收資料夾中的已傳輸檔案則由使用者自行管理。

## 直接連線

直接連線適用於 Windows PC 與 iPhone、iPad 或 Mac 位於同一個可互通的 Wi‑Fi 網路。按下 **建立傳輸** 後，Apple 裝置掃描 QR Code，Windows 使用者核准連線後即可雙向傳檔。檔案不會通過外部伺服器。

## 自訂伺服器紀錄

在首頁按 **連線設定**，輸入下列資料後按 **儲存伺服器**：

| 欄位 | 範例 | 必要性 |
|---|---|---|
| 名稱 | `公司中繼站` | 必填 |
| 訊號伺服器網址 | `wss://relay.example.com` | 必填；必須使用 `wss://` |
| TURN 位址 | `turns:relay.example.com:5349?transport=tcp` | 必填；可輸入多個 `turn:` 或 `turns:` 位址 |
| 使用者名稱 | `lanlift-user` | 依伺服器設定 |
| 憑證或短期權杖 | 由伺服器管理員提供 | 依伺服器設定 |

伺服器紀錄保存後可以選擇「使用」、編輯或刪除。Windows 會加密保存憑證；編輯紀錄時若將憑證欄留空，原有憑證會保留。

目前自訂伺服器介面已完成設定、歷史與安全保存；要建立跨網路傳輸，伺服器端需部署與 LanLift 相容的 **WebSocket 訊號服務**與 **TURN**。詳細服務架構請參閱 `REMOTE_TRANSPORT_OPTIONS.md` 與 `FREE_RELAY_OPTIONS.md`。

## 驗證結果

本版自動化驗證包括一次性配對、上傳、下載、工作階段到期、資料夾 ZIP 壓縮、暫存 ZIP 清除、自訂伺服器憑證加密保存、重啟後設定保留、模式切換與紀錄刪除。另於 759 px 寬度驗證版面無水平溢出，右欄卡片不重疊。
